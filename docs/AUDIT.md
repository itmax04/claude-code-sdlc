## Что сохранено из исходного SDLC
Правило risk → process, смысловые уровни intent/spec/plan, один источник истины, правдивые доказательства (PASS/FAIL/NOT RUN),
обратные связи verify/review → build, maintain → новый intent, incident из любой фазы, ворота H-x Lingo и все жёсткие правила
($0, секреты, приватность, отсутствие оценки произношения, allow-list зависимостей, contracts-first, ночное окно для дорогих прогонов,
production и аккаунты — только владелец).

## Остаточные риски
- Хуки зависят от `python3` в PATH (на macOS есть всегда). Если его нет, хуки пропускают действие, но permissions проекта остаются.
- Bash-guard — эвристика по тексту команды, а не песочница. Изощрённая команда может её обойти. Поэтому `permissions.deny` проекта и
  CI остаются вторым слоем.
- Сквозной прогон с моделью в рамках этой работы не выполнялся: CLI на машине не авторизован, вход — действие владельца.
  Проверены: валидатор плагина и маркетплейса (`--strict`), установка маркетплейса и плагина в изолированный конфиг Claude Code 2.1.309 (5 навыков, 2 агента, 4 события хуков, ≈ 424 токена постоянной нагрузки), инициализация профиля Lingo на временном клоне репозитория, 31 автотест скриптов и хуков на Python 3.9 и 3.12.
